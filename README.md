# Verilog HDL Digital Circuits

This repository contains Verilog HDL implementations of fundamental digital circuits, including:

- Logic Gates (AND, OR)
- Flip-Flops (SR, JK, D, T)
- Synchronous Counter
- Asynchronous (Ripple) Counter

Each module includes:
- Verilog source code
- Testbench for verification
- Simulation waveforms

## Tools Used
- Verilog HDL
- ModelSim / Vivado Simulator
- Icarus Verilog

## Project Objectives
- Understand combinational and sequential logic design
- Learn Verilog HDL coding and simulation
- Verify circuit functionality using testbenches and waveforms

## Results
All designs were successfully simulated, and the generated waveforms confirm the expected behavior of logic gates, flip-flops, synchronous counters, and asynchronous counters.
